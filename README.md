# ImageToolsPro
Suite de herramientas de imagen gratuita y 100% local para artistas.

_**Características y funciones de la aplicación:**_

**-Convertir:**   Transforma imágenes, vídeos y SVG a varios formatos (JPG, PNG, WebP, etc.) o extrae fotogramas.
**-Comprimir:**   Reduce el tamaño exacto del archivo degradando calidad, con vista previa y lupa en tiempo real.
**-Imagen a Vector:**   Convierte imágenes ráster a SVG (en blanco y negro o color).
**-Pulir Bordes:**   Aplica anti-aliasing para suavizar contornos sin desenfocar el interior.
**-Paleta de Colores:**   Extrae los tonos principales (hasta 256) y los exporta a CSS o JSON.
**-Marca de Agua:**   Añade texto personalizado (único o en mosaico) a varias imágenes a la vez.
**-Redimensionar:**   Ajusta tamaño, resolución y parámetros de impresión (DPI/CMYK) en lote.
**-Limpiar EXIF:**   Revisa y elimina metadatos por categorías (GPS, fecha, ICC, etc.).
**-Vista Redes:**   Adapta y previsualiza imágenes según las medidas de distintas plataformas sociales.
**-Optimizar GIF:**   Reduce el peso de animaciones ajustando colores, escala, FPS o fotogramas.
**-Press Kit:**   Genera de forma guiada un paquete de recursos gráficos (avatar, banner, iconos, etc.).
**-Escalar con IA local:**   Aumenta la resolución ($\times 2$ a $\times 8$) sin conexión a internet mediante FSRCNN.

_ENGLISH_

Application Features and Functions:

**-Convert:**   Transform images, videos, and SVGs to various formats (JPG, PNG, WebP, etc.) or extract frames.
**-Compress:**   Reduce the exact file size while degrading quality, with real-time preview and zoom.
**-Image to Vector:**   Convert raster images to SVG (black and white or color).
**-Smooth Edges:**   Apply anti-aliasing to smooth edges without blurring the interior.
**-Color Palette:**   Extract primary colors (up to 256) and export them to CSS or JSON.
**-Watermark:**   Add custom text (single or tiled) to multiple images at once.
**-Resize: Adjust size, resolution, and print parameters (DPI/CMYK) in batches.
**-Clean EXIF:**   Review and remove metadata by category (GPS, date, ICC, etc.). -Network View: Adapts and previews images according to the dimensions of different social media platforms.
**-Optimize GIFs:**   Reduces the file size of animations by adjusting colors, scale, FPS, or frame rate.
**-Press Kit:**  Generates a package of graphic resources (avatar, banner, icons, etc.) with guided instructions.
**-Local AI Scale:**   Increases resolution ($\times 2$ a $\times 8$) offline using FSRCNN.
